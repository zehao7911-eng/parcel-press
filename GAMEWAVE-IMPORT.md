# GameWave import

Import the ZIP with index.html at its root. The app starts without the optional window.neonlib injection and uses the actual CSS viewport. The GameWave reference was rechecked on 2026-11-09.

The first meaningful fold attempt starts a round. A resumed fold or seal starts the restored visit on its first committed action. A sealed parcel or explicit restart ends an active round. Opening a drawer or reading a receipt does not send lifecycle events.

The parcel-press-v1 local key contains the active parcel and profile. The cloud envelope is scoped to parcel-press and stores only the profile. A recognized profile merges best stars and one-time unlock flags. An unfinished parcel remains in local storage. Unknown cloud envelopes are left alone.

Like and comment registration are independent and use the direct callback event. A positive like unlocks Blue Porcelain and a confirmed direct comment, including an empty image comment, unlocks Berry Foil. Both are also available by earning stars. Callback flags prevent repeat awards within the supported local and cloud save scope.
